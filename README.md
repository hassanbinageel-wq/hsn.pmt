# hsn.pmt — تطبيق إدارة أعمال إنتاج الذكاء الاصطناعي

تطبيق أندرويد يعمل **بالكامل دون إنترنت**، لإدارة تكاليف وأرباح أعمالك (صور/فيديو AI)، العملاء، الاشتراكات، وإصدار الفواتير بصيغة PDF مع الشعار والختم.

- البيانات كلها **مشفّرة ومحفوظة على جهازك فقط** (لا يوجد أي خادم).
- ثلاث عملات: ريال سعودي، دولار، ريال يمني — بأسعار صرف يدوية.
- فواتير PDF عربية سليمة + مشاركة عبر واتساب.
- نسخ احتياطي مشفّر + تصدير CSV.

---

## أولًا: تشغيل تجريبي على المتصفح (اختياري)
```bash
cd hsn-pmt
npm install
npx serve www      # أو: python3 -m http.server -d www 8080
```
افتح الرابط في المتصفح. (بعض الميزات مثل واتساب ومشاركة الملفات تعمل بشكلها الكامل داخل التطبيق على الجوال فقط.)

---

## ثانيًا: بناء ملف APK عبر GitHub (بدون أندرويد ستوديو)

### 1) أنشئ مستودعًا (Repository) جديدًا على GitHub
- اسم مقترح: `hsn-pmt` — اجعله **Private** إن رغبت.

### 2) ارفع ملفات المشروع
ارفع **كل محتويات مجلد `hsn-pmt`** إلى المستودع (زر **Add file → Upload files**)، ما عدا مجلد `node_modules` (غير موجود أصلًا في الحزمة).

> ⚠️ **مهم جدًا — مجلد `.github`:**
> رفع الملفات من متصفح GitHub **يتجاهل المجلدات التي تبدأ بنقطة** مثل `.github`. لذلك ملف البناء موجود عندك باسم:
> ```
> github-workflow/build.yml
> ```
> يجب إنشاؤه يدويًا داخل المستودع بالمسار الصحيح:
> 1. في المستودع اضغط **Add file → Create new file**.
> 2. في خانة الاسم اكتب بالضبط:
>    ```
>    .github/workflows/build.yml
>    ```
>    (سيتحول تلقائيًا إلى مجلدات فور كتابة `/`).
> 3. الصق داخله **كامل محتوى** ملف `github-workflow/build.yml`.
> 4. اضغط **Commit**.

### 3) شغّل البناء
- انتقل لتبويب **Actions** في المستودع.
- اختر **build-apk** ثم **Run workflow** (أو سيبدأ تلقائيًا بعد أي رفع لفرع `main`).
- انتظر انتهاء البناء (عادة ٣–٧ دقائق) حتى تظهر علامة ✅.

### 4) نزّل التطبيق
- افتح عملية البناء المكتملة → في الأسفل قسم **Artifacts** → نزّل **hsn-pmt-apk**.
- سيكون ملف مضغوط يحتوي `app-debug.apk`. فُكّ الضغط.

### 5) ثبّت APK على جوال أندرويد
- انقل الملف للجوال، افتحه.
- عند ظهور تحذير «مصادر غير معروفة» اسمح بالتثبيت لهذا الملف.
- افتح التطبيق مباشرةً — يعمل بدون كلمة مرور.

---

## تحديث التطبيق لاحقًا دون فقد البيانات
البيانات محفوظة داخل التطبيق وتبقى عند التحديث بشرطين:

1. **لا تحذف التطبيق القديم.** ثبّت النسخة الجديدة **فوق** القديمة مباشرة (تحديث لا حذف). الحذف يمسح البيانات.
2. **لا تغيّر مفتاح التوقيع.** أبقِ ملف `keystore/debug.keystore` كما هو في المستودع؛ فهو يضمن نفس التوقيع في كل بناء ليقبل الجوال التحديث فوق القديم.

خطوات التحديث: عدّل ما تريد في الكود → ارفع التغييرات → شغّل البناء → نزّل APK الجديد → ثبّته فوق القديم.

> إن أردت نقل بياناتك لجوال آخر، أو الاطمئنان قبل أي تحديث: اعمل **نسخة احتياطية** من داخل التطبيق (المزيد → النسخ الاحتياطي → تصدير)، ثم استوردها في الجهاز الجديد بعد إنشاء كلمة مرور جديدة.

---

## النسخ الاحتياطي والاستعادة
- **تصدير:** المزيد → النسخ الاحتياطي → «تصدير نسخة احتياطية» → أدخل كلمة مرور للنسخة → احفظها في مكان آمن (Google Drive مثلًا). الملف بامتداد `.hsnbak` ومشفّر.
- **استعادة:** «استيراد نسخة احتياطية» → اختر الملف → أدخل كلمة مروره → ستظهر لك محتوياته، ثم اختر **دمج** (إضافة الجديد فقط) أو **استبدال** (مسح الحالي ووضع النسخة).
- **CSV:** لتصدير الأعمال أو الفواتير كجداول Excel.

## ملاحظات
- أسعار الصرف يدوية بالكامل (لا تُجلب من الإنترنت). حدّثها من: المزيد → العملات وأسعار الصرف. إن نقص سعر عملة يظهر تنبيه ولا تُحتسب مبالغها.
- الأيقونة الحالية مؤقتة داخل `resources/` ويمكن استبدالها بصورة 1024×1024 بنفس الأسماء.
- معرّف التطبيق: `com.hsnpmt.app` (لا تغيّره بعد أول تثبيت حتى تبقى التحديثات والبيانات سليمة).

## جديد الإصدار 1.1
- **يفتح بدون كلمة مرور** — مباشرة إلى الواجهة الرئيسية. (النسخة الاحتياطية تبقى مشفّرة بكلمة مرور عند التصدير.)
- **الاشتراكات كأدوات:** تضيف الأداة **مرة واحدة** مع شعارها، ثم تسجّل **تجديداتها/دفعاتها** لاحقًا من داخلها (مبلغ + تاريخ) دون إعادة كتابة الاسم.
- **الخصم التلقائي:** تكلفة عناصر الإنتاج في أعمالك تُخصم مباشرةً من رصيد الاشتراكات (عملية متصلة)، وتظهر في شاشة الاشتراكات: المدفوع / المستهلك / المتبقي.
- **عناصر الإنتاج كجداول:** جدول للقطات الفيديو وجدول للصور، لكل عنصر سعره الخاص، مع **مجموع تلقائي** لكل جدول و**مجموع كلي** للتكلفة.
- **العميل من جهات الاتصال:** زر لاختيار جهة اتصال يملأ الاسم والرقم تلقائيًا. (يطلب صلاحية «جهات الاتصال» أول مرة — مضافة تلقائيًا في ملف البناء.)
- **تخصيص الواجهة الرئيسية:** إضافة صورة غلاف وكتابة العنوان الرئيسي يدويًا (المزيد → تخصيص الواجهة الرئيسية، أو زر التعديل أعلى الرئيسية).
- **فاتورة PDF بتصميم احترافي محدّث.**
- شعار وهوية التطبيق: **hsn.pmt** (أبيض · زمردي · أسود).

> ملاحظة: صلاحية جهات الاتصال تُضاف تلقائيًا للمانيفست أثناء البناء عبر خطوة في `github-workflow/build.yml`. إن لم يظهر منتقي جهات الاتصال، امنح التطبيق صلاحية «جهات الاتصال» من إعدادات النظام.

## جديد الإصدار 1.2
- **نظام الرصيد (Credits) للأدوات:** كل اشتراك يعطيك رصيد Credits مقابل مبلغ، فيُحسب **سعر الرصيد الواحد** تلقائيًا (مثال: ‎$20‎ ↔ 500 Credit = ‎$0.04‎ لكل Credit).
- **تكلفة الإنتاج بالـ Credits:** في العمل تختار الأداة، وتُدخل لكل لقطة/صورة **عدد الـ Credits**، فيحسب التطبيق **المبلغ تلقائيًا** ويجمعه، ويُخصم من رصيد الأداة (المستهلك/المتبقّي بالـ Credits وبالمبلغ).
- **الوضع الفاتح والداكن:** من «المزيد» تختار فاتح / داكن / تلقائي (يتبع نظام الجهاز).
- **الشعار نصّي:** hsn.pmt (‏hsn أبيض · ‏.pmt زمردي) في الأيقونة وأعلى الواجهة الرئيسية.
- تم إجراء **اختبار تشغيل كامل للتطبيق** (إنشاء أداة/عميل/عمل + الفواتير + كل الشاشات) والتأكد من خلوّه من أخطاء التشغيل.
